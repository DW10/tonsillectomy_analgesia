Step 2B - Masking of Identifiers with random ID’s

The Anesthatist_ID columns have been masked prior to this step by using the DurableKey of the staff member and renaming with an integer list.

We require EncounterKey as we use it for subsetting and joins in the analysis script. We will replace with a randomised Integer.

We will re-assign the patient_id column with a new interger that is now sampled randomly (as opposed to the sample in order of the database order.

#Sample the unique encounterkeys, randomise the order then add an index. 
mapping_table_encounter <- data.frame(EncounterKey = unique(anon_df$EncounterKey)) %>%

Step 2C Shifting of dates

We use the various date columns to derive important time durations (Length of surgery, length of admission). We will shift dates by a random duration sampled from a uniform distribution. We will then apply the same duration to each date column in that row using rowwise() to ensure that the time intervals are kept consistant. We will use +/- 5 weeks as the duration to sample from.

We use this approach to preserve the time based features (eg rate of cobaliton by year) as opposed to anchoring to dates.

gen_interval <- function(weeks){
  # Sample the scalar value
  sampled_value <- runif(1, min = -weeks, max = weeks)
  # Return as a lubridate duration (defaults to seconds)
  return(dweeks(sampled_value))
}


# Generate a random interval for each row

date_cols <- c("TouchTimeStartInstant", "TouchTimeEndInstant",
              "InRecoveryInstantTracking","InRecoveryInstantTracking",
              "RecoveryCareCompleteInstantTracking","OutofRecoveryInstantTracking"  )

anon_df <- anon_df %>%
  rowwise() %>%
  mutate(
    diff_time = gen_interval(5), 
    across(all_of(date_cols), ~ .x + diff_time)
  ) %>%
  ungroup() %>%
  select(-diff_time)
